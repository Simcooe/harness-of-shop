\datedsubsection{\textbf{Shopping Agent：面向多轮导购的 Harness 设计与过程评测}}{2026.10 - 至今}
项目背景: 针对购物 Agent 在多轮导购中未经用户确认即下单、难以利用用户画像的问题，不改模型权重，以评测驱动 Harness 迭代。


\begin{itemize}[parsep=0.5ex]
 \item \textbf{Harness 架构设计}: 定位到单 Agent 问询后连续操作越多越易跳过确认（操作 4 步以上时 91\% 的下单未经确认），据此拆分导购与买手，需求单、候选单逐条溯源至用户原话与页面原文，下单须用户明确确认；严格成功率 50\% $\rightarrow$ 90\%，用户确认后买对 22\% $\rightarrow$ 56\%
\end{itemize}

\begin{itemize}[parsep=0.5ex]
 \item \textbf{过程评测体系}: 不依赖环境奖励，以原子约束 rubric 逐条核验所购商品，新增“用户确认后买对”指标；LLM 评审按 5 个维度评估轨迹，以下单前用户原话附注与分数上限校准评审盲区；对模拟用户做质检，修正其凭空追加购买条件的问题（50 题中 22 题 $\rightarrow$ 5 题）
\end{itemize}

\begin{itemize}[parsep=0.5ex]
 \item \textbf{失败归因与迭代}: 以里程碑漏斗定位首个错误动作，并按约束来源（用户原话 / 画像）分组核验，定位画像场景的两类主因：近期搜索未被利用、被无关偏好品牌带偏；据此设计画像分级（近期搜索作为约束，长期偏好仅作排序参考），严格成功率 66\% $\rightarrow$ 81\%（同样规则仅写入提示词为 71\%）
\end{itemize}
